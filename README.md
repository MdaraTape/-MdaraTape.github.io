# Tinerombo T. Mudzimbasekwa — Portfolio

A personal portfolio website for **Tinerombo T. Mudzimbasekwa**, a software developer building
practical, intelligent, and user-focused solutions across web, mobile, and machine learning.

🔗 **Live site:** https://mdaratape.github.io/-MdaraTape.github.io/

## Overview

A single-page, responsive portfolio built with plain HTML, CSS, and vanilla JavaScript — no
frameworks or build step. It is deployed with GitHub Pages.

Sections:

- **Hero** — full-bleed background image with an animated intro
- **About** — portrait, bio, and a "Quick Facts" panel
- **Projects** — The Barber Force, Graduation Glamour, Fatigue Detection System, Agrivus, and
  Statix Electricity, with an image gallery and lightbox
- **Skills** — technologies and practices grouped by category
- **Contact** — contact details, social links, and a message form

## Tech

- HTML5
- CSS3 (custom properties, grid/flex layouts, responsive design, glassmorphism, animations)
- Vanilla JavaScript (mobile nav, scroll-reveal, image lightbox, gallery modal, contact form)
- Google Fonts (Playfair Display + Inter)
- GitHub Pages for hosting

## Running locally

No build step is required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/MdaraTape/-MdaraTape.github.io.git
cd -MdaraTape.github.io
# then open index.html in your browser
```

Or serve it with any static server, for example:

```bash
python -m http.server 8000
# visit http://localhost:8000
```
